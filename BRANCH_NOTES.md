# Branch Notes: Codebase Indexing

## Overview

Codebase Indexing enables Cursor to understand your entire project. With @codebase, you can ask questions about any part of your code, find patterns, and get context-aware suggestions across your whole repository.

## What is Codebase Indexing?

Cursor indexes your project files to:
- Understand project structure
- Find relevant code quickly
- Provide better context in responses
- Enable @codebase searches
- Improve autocomplete and suggestions

## Key Features

1. **@codebase Searches** - Query entire project
2. **Semantic Understanding** - Finds conceptually related code
3. **Fast Navigation** - Jump to relevant files instantly
4. **Better Context** - AI understands full project
5. **Pattern Detection** - Finds similar code structures

## Using @codebase

In Chat or Composer, use @codebase to search:

```
@codebase Where is user authentication implemented?
@codebase How do we handle errors across the project?
@codebase What testing frameworks are we using?
@codebase Find all database queries
```

## Best Practices

1. **Be Specific:** "@codebase Find React components that use useState"
2. **Ask About Patterns:** "@codebase How do we structure API routes?"
3. **Find Implementations:** "@codebase Where is JWT validation done?"
4. **Discover Dependencies:** "@codebase What npm packages handle authentication?"

## Common Use Cases

- Understanding unfamiliar codebases
- Finding where functionality lives
- Discovering coding patterns
- Locating similar implementations
- Identifying dependencies
