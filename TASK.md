# Tasks: Custom Prompts and Rules

Practice creating and using `.cursorrules` for your projects.

## Exercise 1: Create Basic .cursorrules

**Task:**
Create a `.cursorrules` file with:
- Project tech stack
- Basic code style preferences
- File organization structure

**Test:**
Ask Chat: "What are the coding standards for this project?"
Verify it references your rules.

---

## Exercise 2: Add Framework Rules

**Task:**
Add framework-specific rules for:
- Component patterns
- State management
- Routing conventions
- File naming

**Test:**
Ask Composer to create a component.
Verify it follows your rules.

---

## Exercise 3: Enforce Testing Standards

**Task:**
Add rules for:
- Testing framework
- Test file naming
- Coverage requirements
- What to test

**Test:**
Ask Agent to add tests.
Verify tests follow your standards.

---

## Exercise 4: Security Guidelines

**Task:**
Add security rules:
- Input validation requirements
- Authentication patterns
- Error handling
- Logging guidelines

**Test:**
Ask for API endpoint creation.
Verify security measures are included.

## Exercise 5: Documentation Standards
