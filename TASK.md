# Tasks: Cloud Agents

Practice parallel execution with multiple agents.

## Note

Cloud Agents require a Cursor Pro subscription and may have usage limits. These exercises are conceptual if you don't have access yet.

## Exercise 1: Parallel Testing

**Task:**
Spawn 3 agents:
- Agent 1: "Add unit tests to all files in src/auth/"
- Agent 2: "Add unit tests to all files in src/api/"
- Agent 3: "Add unit tests to all files in src/utils/"

**Monitor:** Check each agent's progress independently

**Review:** Ensure all tests are consistent in style

---
