# Tasks: Plan Mode

Practice using Plan Mode for complex, high-stakes tasks.

## Exercise 1: Framework Migration Plan

**Task:**
"Create a plan to migrate a React class-based component library to functional components with hooks. Don't execute yet, just create the plan."

**Review:**
- Are all components identified?
- Is the migration order logical?
- Are tests included?
- Is backward compatibility considered?

---

## Exercise 2: API Redesign Plan

**Task:**
"Plan refactoring of REST API to use GraphQL. Include schema design, resolver implementation, and client migration."

**What to check:**
- Schema completeness
- Migration strategy
- Backward compatibility
- Performance considerations

---

## Exercise 3: Adding Authentication Plan

**Task:**
"Plan implementing OAuth 2.0 authentication across the application, replacing current JWT-only auth."

**Verify plan includes:**
- Provider setup (Google, GitHub)
- User migration
- Session management
- Security considerations

---

## Exercise 4: Database Migration Plan

**Task:**
"Plan migration from MongoDB to PostgreSQL including schema design, data migration, and code updates."

**Check for:**
- Schema mapping
- Data transformation
- Zero-downtime strategy
- Rollback procedures

---

## Exercise 5: Microservices Split Plan

## Exercise 6: i18n Implementation Plan
