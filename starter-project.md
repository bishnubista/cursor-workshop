# Starter Project Structure

This branch provides a minimal project structure. Use Composer to build features within this structure.

## Project Setup

```
project/
├── src/
│   ├── components/     (React components)
│   ├── routes/         (API routes)
│   ├── controllers/    (Business logic)
│   ├── models/         (Data models)
│   ├── middleware/     (Express middleware)
│   ├── utils/          (Utilities)
│   └── config/         (Configuration)
├── tests/              (Test files)
└── README.md
```

## Getting Started

1. Use Composer (Cmd/Ctrl + I) to create features
2. Ask Composer to follow this project structure
3. Build one feature at a time
4. Review generated code carefully
5. Test each feature

## Example Features to Build

- User authentication
- Blog posts CRUD
- Comment system
- File upload
- Search functionality
- Email notifications
- Rate limiting
- Caching layer

Use the exercises in TASK.md as a guide!
