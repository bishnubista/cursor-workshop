# Workshop Overview

Complete guide to all branches and what you'll learn in each.

## Workshop Structure

This workshop is organized into **9 branches** across **3 difficulty levels**. Each branch is a hands-on learning experience with detailed notes and practical exercises.

---

## Beginner Level (Branches 01-03)

### 01-beginner/chat-and-context
**What you'll learn:**
- Using Cursor Chat (Cmd/Ctrl + L)
- @-mentions for context (@file, @folder, @codebase)
- Asking effective questions
- Understanding code with AI assistance
- Debugging with Chat

**Key exercises:**
- Basic chat interactions
- File context with @file
- Code explanations
- Multi-file understanding
- Codebase-wide queries

## Recommended Learning Paths

### Path 1: Complete Beginner
Start from branch 01 and progress sequentially through all branches.

```bash
git checkout 01-beginner/chat-and-context
# Complete exercises
git checkout 02-beginner/tab-autocomplete
# Complete exercises
# ... continue through all branches
```

### Path 2: Some Experience
If you've used AI coding assistants before:
1. Quickly review branches 01-03 (beginner)
2. Focus on branches 04-09 (intermediate/advanced)

### Path 3: Power User
Already comfortable with Cursor basics:
- Jump to branch 07 (Plan Mode)
- Continue through branches 08-09

### Path 4: Topic-Focused
Pick specific branches based on what you want to learn:
- **Need better at Chat?** → Branch 01
- **Want to build features?** → Branches 04, 07
- **Automate tasks?** → Branches 05, 08
- **Team workflows?** → Branch 09

## How to Use This Workshop

### 1. Clone the Repository
```bash
git clone <repository-url>
cd cursor-workflow
```

### 2. Start with Main Branch
Read README.md and GETTING_STARTED.md

### 3. Choose Your First Branch
```bash
git checkout 01-beginner/chat-and-context
```

### 4. In Each Branch:
1. Read `BRANCH_NOTES.md` thoroughly
2. Open `TASK.md` and complete exercises
3. Practice with the sample code files
4. Complete self-assessment
5. Move to next branch

### 5. Take Notes
Keep a learning journal:
- What worked well?
- What shortcuts do you now use?
- What patterns emerged?
- What will you apply to your work?

## Common Questions

**Q: Do I need to complete all branches?**
A: No, you can pick branches based on your interests and needs.

**Q: Can I skip beginner branches?**
A: If you're already using Cursor, you can. But they have useful tips even for experienced users.

**Q: How long does the full workshop take?**
A: 25-34 hours depending on your pace and prior experience.

**Q: Is this workshop free?**
A: The workshop is free. You need Cursor (free tier works for basics, some features need Pro).

**Q: Can I use this for team training?**
A: Yes! It's designed for individual learning or team workshops.

**Q: What if I get stuck?**
A: Use Cursor Chat for help, check the docs, or ask in Cursor Forum.
