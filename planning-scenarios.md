# Plan Mode Scenarios

## Scenario 1: Legacy Code Modernization

**Context:** 10-year-old jQuery application needs modernization

**Task for Plan Mode:**
"Create a plan to migrate jQuery application to React while maintaining all functionality. Plan should include phases, risk mitigation, and testing strategy."

**Expected Plan Elements:**
- Audit of current functionality
- Component architecture design
- Migration phases (routing, state, UI)
- Testing at each phase
- Gradual rollout strategy

---

## Scenario 2: Security Hardening

**Context:** Application needs security audit and fixes

**Task for Plan Mode:**
"Plan comprehensive security hardening including authentication, authorization, input validation, and HTTPS enforcement."

---

## Scenario 3: Multi-tenant Architecture

**Context:** Single-tenant SaaS needs to become multi-tenant

**Task for Plan Mode:**
"Plan adding multi-tenancy with data isolation, tenant management, and per-tenant customization."

---

## Practice Tips

1. Start with smaller planning tasks
2. Review plans before execution
3. Break large plans into phases
4. Always include testing
5. Consider rollback strategies

Happy planning!
